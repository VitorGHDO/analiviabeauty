# Ana Lívia Beauty — site

Landing page da Ana Lívia Beauty, cabeleireira domiciliar em Contagem, BH e região. Feito em [Astro](https://astro.build).

- Para editar textos, fotos e WhatsApp: veja **[COMO-EDITAR.md](COMO-EDITAR.md)**.
- Todo o conteúdo fica em `src/conteudo/site.yaml`.

```
npm install      # uma vez
npm run dev      # ver o site em http://localhost:4321
npm run build    # gerar o site pronto na pasta dist
```
