# Listras

Listras verticais em magenta, a estampa que aparece em quase todas as aplicações da marca (avental, mala, cartão de boas-vindas, posts).

```html
<div class="al-post al-listras" data-theme="magenta">…</div>
```
- `al-listras`: magenta + `beleza-intimista`. `--vivo`: magenta + `rosa-vivo`. `--raizes`: `raizes` + magenta. `--creme`: magenta + creme.
- Largura de cada listra: 56 px (troque com `--listra`, entre 40 e 72 px).
- Use como fundo inteiro do post ou de uma faixa lateral. Texto nunca vai direto em cima das listras: ponha um `PainelOndulado`, um cartão ou um sticker.
