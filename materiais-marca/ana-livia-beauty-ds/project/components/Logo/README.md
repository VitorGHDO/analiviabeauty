# Logo

Qual arquivo de logo usar em cada fundo e onde colocá-lo no post.

| Fundo | Logo | Assinatura completa (com mascote) |
| --- | --- | --- |
| creme (`auto-cuidado`), rosa (`beleza-intimista`) | `logo-ana-livia-calmaria.svg` ou `logo-ana-livia-magenta.svg` | `assinatura-completa-calmaria.svg` |
| calmaria, raízes, fotos escuras | `logo-ana-livia-creme.svg` | `assinatura-completa-creme.svg` |
| magenta (`rosa-fora-da-caixa`) e listras | `logo-ana-livia-para-fundo-magenta.svg` | `assinatura-completa-para-fundo-magenta.svg` |

- O logo é a caligrafia “Ana Lívia” com a estrela magenta entre as palavras e “Beauty” em Inter Bold magenta. Nunca redesenhe, nunca troque as fontes, nunca separe a estrela.
- No post, o logo fica pequeno (150 px de largura, `al-marca`) no canto inferior. O logo grande é só para capas, destaques e o post de apresentação.
- A assinatura completa (mascote + logo + anel “seu cabelo · seu jeito · no seu tempo”) é para capa de destaque, avatar e posts institucionais.
- Respiro mínimo em volta: a altura da letra “a” do logo.
- As versões calmaria e magenta são recolorações exatas do desenho original (mesmo traçado), feitas para fundos claros.
