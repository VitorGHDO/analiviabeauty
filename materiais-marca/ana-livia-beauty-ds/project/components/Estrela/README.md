# Estrela

A estrela de quatro pontas da marca: o brilho de se cuidar. Faz o papel das estrelinhas que enfeitam os posts de referência.

```html
<svg class="al-estrela al-estrela--lg" viewBox="1534.43 467.99 80.16 78.49" aria-hidden="true">
  <path transform="matrix(1,0,0,-1,1611.142,509.282)" d="M0 0C-14.467-7.947…Z"/>
</svg>
```
Copie o `<svg>` inteiro de `preview.html` (o desenho é o mesmo de `estrela-*.svg`). A cor vem de `acento`; para outra cor, troque `color`.

- Tamanhos: `al-estrela--sm` 36 px, padrão 64 px, `al-estrela--lg` 110 px.
- Use de uma a três por post: uma grande perto do título e uma ou duas pequenas soltas (`al-solta` + `top/left`).
- Fica acima ou ao lado do título, nunca em cima do texto.
- É o único ícone decorativo. Não use emoji, brilhos de outros estilos nem estrelas de cinco pontas.
