# PostServicos

Cardápio de serviços: três cartões magenta empilhados, cada um com um sticker de pessoa saltando para fora, e o telefone embaixo.

Referência: post central do grid (Escova profissional, Corte de cabelo, Hidratação capilar). As fotos recortadas viram stickers.

## Para montar
- Fundo `creme`. Três `CartaoServico`, alternando o do meio com `--invertido`, 96 px entre eles.
- Sticker de cada cartão combina com o serviço (chanel → escova, coque → corte, cachos → hidratação).
- `BotaoAgende` centralizado na base.
- Para mais serviços, faça um carrossel: três cartões por imagem.
