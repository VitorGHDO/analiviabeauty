# Circulado

A elipse fina desenhada à mão em volta de uma palavra, como no manual (“até você”, “Beauty house.”, “capilar”).

```html
<span class="al-circulado">até você</span>
<span class="al-circulado al-circulado--acento">capilar</span>
```
- O traço usa `linha` (`traco-fino`, 3 px) e gira −3°. `al-circulado--acento` pinta o traço com `acento`.
- Uma vez por post, em uma palavra ou expressão curta (até 3 palavras).
- Funciona em título itálico, na pesada e na manuscrita.
