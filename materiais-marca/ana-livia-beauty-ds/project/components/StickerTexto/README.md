# StickerTexto

Frases curtas como adesivo recortado: pesada (Impacto) com contorno creme grosso, igual aos stickers ilustrados.

```html
<span class="al-sticker-texto impacto-md">cuidado<br>em casa<svg class="al-estrela">…</svg></span>
<h2 class="al-titulo-adesivo impacto-lg">Finalização<br>ondulada</h2>
```
- `al-sticker-texto`: bloco calmaria com letra `creme-logo` e contorno `contorno-sticker` (`traco-sticker`). Variações `--magenta` e `--rosa`. Gira −6° (troque com `--giro`).
- Pode levar uma estrela no canto (o `<svg class="al-estrela">` dentro do sticker já se posiciona).
- `al-titulo-adesivo`: título em calmaria com contorno creme, direto sobre foto (“Finalização ondulada”).
- Textos aprovados: “cuidado em casa”, “Beauty”, “Cabeleireira Domiciliar”, nomes de serviço curtos.
- No máximo dois stickers de texto por post.
