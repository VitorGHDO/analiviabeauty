# PostCombos

Combos da semana dentro do painel ondulado calmaria, por cima das listras magenta, com dois combos e o telefone.

Referência: post “Combos da semana” do grid, montado com o painel e as listras do post “Como funciona o beauty house?” do manual.

## Para montar
- Post `al-listras al-listras--vivo` com `data-theme="magenta"`.
- `PainelOndulado` com `data-theme="calmaria"` ocupando quase tudo; dentro: estrela, título misto, dois `al-combo`, `BotaoAgende`.
- Duas anotações manuscritas no alto do painel.
- Fora do painel, na base: sticker de texto “cuidado em casa” e um sticker de pessoa.
- Os preços da prévia são exemplos.
