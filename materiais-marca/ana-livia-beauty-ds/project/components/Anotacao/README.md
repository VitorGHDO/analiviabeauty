# Anotacao

Palavras soltas na letra manuscrita (Sunset Script no original, Just Me Again Down Here na web), como bilhetinhos em volta do título ou da foto.

```html
<span class="al-anotacao manuscrita-md" style="top:120px; left:430px">exclusividade</span>
```
- Sempre em minúsculas. `manuscrita-lg` para a anotação principal, `manuscrita-md` para palavras soltas.
- Cor `acento` por padrão; `al-anotacao--tinta` para a cor do texto. Gira −4° (troque com `--giro`).
- Até quatro por post. Use palavras da marca: exclusividade, auto cuidado, autenticidade, sensibilidade, beleza em casa, do seu jeito, no seu tempo!, beleza em cada detalhe, cronograma capilar.
- Nunca use a manuscrita para frases longas, preços ou telefone.
