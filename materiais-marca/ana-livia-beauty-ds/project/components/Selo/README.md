# Selo

Os quatro selos redondos do manual: logo nas listras, mascote, “cuidado em casa” e “seu cabelo · seu jeito · no seu tempo”.

```html
<img class="al-selo" src="selo-seu-cabelo-seu-jeito.png" alt="" style="--giro:8deg">
```
- PNG redondos de 270 px: use até 240 px de largura no post para manter a nitidez.
- Um por post, girado, perto de uma borda ou sobrepondo o canto de uma foto ou cartão.
- Também servem de capa de destaques do Instagram.
