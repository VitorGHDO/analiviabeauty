# PostTransforme

Chamada de transformação com foto em tela cheia, véu raízes subindo da base e título misto no canto inferior esquerdo.

Referência: post “Transforme seu visual!” do grid.

## Para montar
- Fundo `raizes` com `al-foto-fundo` (cabelo de costas ou de lado, em movimento) e `al-veu` de baixo para cima.
- Título misto: “TRANSFORME” em `impacto-xl` caixa alta + “seu visual!” em `titulo-xl` `al-cor-acento`, com duas estrelas.
- `BotaoAgende` na variação `--contorno --esquerda`.
- Também serve para “Antes e depois”, “Finalização ondulada” e “Corte novo”.
