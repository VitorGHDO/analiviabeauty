# Stickers

Ilustrações da marca com contorno creme recortado (#fdedd3), em SVG vetorial tirado do manual. Use sempre o arquivo inteiro, sem recolorir.

- `mascote-ana-livia.svg` — a persona Ana Lívia, cabelo cacheado, mão no rosto.
- `sticker-cachos-coracao.svg` — menina de cachos volumosos com coração magenta.
- `sticker-coque-piscadinha.svg` — menina de coque piscando, com brilho.
- `sticker-chanel-brilho.svg` — menina de cabelo chanel com estrela.
- `sticker-secador.svg` — secador magenta.
- `sticker-mascara-capilar.svg` — pote de máscara capilar com coração.
- `sticker-tigela-pincel.svg` — tigela de coloração com pincel magenta.
