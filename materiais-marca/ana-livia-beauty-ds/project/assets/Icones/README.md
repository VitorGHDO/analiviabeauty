# Ícones

Os quatro ícones próprios da marca, em SVG de uma cor só. Cada um existe em quatro tintas, indicadas no nome: creme (#fff7e6), rosa (#f4b3bf), magenta (#b40252) e calmaria (#42412c).

- `raizes-*.svg` — raízes do cabelo: origem, couro cabeludo, tratamento.
- `tesoura-*.svg` — tesoura: transformação, corte.
- `movimento-*.svg` — mecha em movimento: finalização, escova.
- `estrela-*.svg` — estrela de quatro pontas: autocuidado, brilho. Para recolorir livre, use o `<svg>` em linha do componente Estrela.

Escolha a tinta que contrasta com o fundo: creme ou rosa nos escuros, magenta ou calmaria nos claros.
