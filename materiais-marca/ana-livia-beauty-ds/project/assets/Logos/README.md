# Logos

Logo, assinatura completa e monograma, recortados do arquivo vetorial do manual. Nenhum foi redesenhado.

- `logo-ana-livia-creme.svg` — letras creme (#fffdde), estrela e “Beauty” magenta. Para calmaria, raízes e fotos escuras.
- `logo-ana-livia-calmaria.svg` — letras calmaria, estrela e “Beauty” magenta. Para creme e rosa.
- `logo-ana-livia-magenta.svg` — letras magenta, estrela e “Beauty” calmaria. Para creme e rosa, quando o post já tem pouco magenta.
- `logo-ana-livia-para-fundo-magenta.svg` — letras creme, estrela e “Beauty” calmaria. Para magenta e listras.
- `assinatura-completa-creme.svg` — mascote + logo + anel “seu cabelo · seu jeito · no seu tempo”, letras creme. Para calmaria e raízes.
- `assinatura-completa-calmaria.svg` — a mesma com letras e anel em calmaria. Para creme.
- `assinatura-completa-para-fundo-magenta.svg` — a mesma com “Beauty” calmaria. Para magenta.
- `monograma-al-contorno-rosa|creme|calmaria|magenta.svg` — o “AL” em contorno fino de uma só cor (a do nome do arquivo). Marca d'água grande, vazando da borda.

As versões calmaria e magenta são recolorações do mesmo traçado original.
